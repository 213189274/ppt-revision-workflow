# 三条智能体工作线


根据当前环境的能力安排三条工作线；无法并行时，由同一执行者依次完成。

## 数据核验：数据与外部证据

**输入**：项目定位、要改的页、现有数字与来源、时间范围、统计对象、所需官方素材、真实图片限制。

**任务**：
1. 核对每项数字的单位、范围、时期、样本定义与计算方法。
2. 区分行业全部职位、特定职业、平台记录、独立职位和招聘人数。
3. 官方政策按真实标题、发布单位与版本核验；截图必须对应实际页面。
4. 企业图片优先官网，招聘要求用招聘网页，不能使用相邻但不对应的素材。
5. 缺失值不补造；允许的估算单独记录方法并给出可见标注方案。

**输出**：来源清单、可用数据表、计算过程、真实截图/素材、未核实项、可用于页面的简洁结论。

**禁止**：直接改另一工作线的页面，擅自把估算当实测，为填满图表拼接不兼容口径，提供未经访问确认的“官网截图”。

## 内容审校：内容与证据审校

**输入**：最新定位、逐页要求、母版文字、已确认成果、图片说明、用户排除项。

**任务**：
1. 清理旧职业、旧产品或旧赛道表述；联动核对背景—政策—需求—任务—证据—规划。
2. 把经历与新的表达目标连接，但保留真实岗位、团队归属与已完成程度。
3. 标题直接写成一句话，突出本页证据支持的能力或结论。
4. 用“替换前/后”明确修改，不用模糊指令让视觉工作线再次理解。
5. 删除冗余说明但保留必要的事实口径；去“拟”时不改变未来时态。

**输出**：逐页文案补丁、标题表、需要保留的事实、证据疑点、与其他页面的冲突或重复。

**禁止**：把真实审计实习删除成不存在、重命名为未担任的分析师岗位、夸大贡献、重编奖项，或在仅改字体时回退文字。

## 视觉编辑：真实素材与页面排版

**输入**：指定页面范围、确认文案、母版风格、字体合同、真实素材、页序映射、明确不改对象。

**任务**：
1. 按原稿修改原生文本框、图表、表格、照片与形状。
2. 解决拥挤、空白失衡、文字重叠、图片错配和字体不一致。
3. 同级模块统一配色和样式；突出数字与结论而非堆砌装饰。
4. 保留已确认的艺术字、人物面貌、证书及Logo原形。
5. 提交页面补丁与预览，清楚声明字体替代、图片质量及可编辑性限制。

**输出**：局部PPT补丁或可重复执行的修改代码、引用素材、修改页预览、视觉自检记录。

**禁止**：AI生图、伪造活动、改变证书/人脸/服装事实，整页重绘后冒充完全可编辑，擅自修改其他已确认页面。

## 主执行者：唯一合并者

主执行者维护版本、页序、需求和字体合同；分配互不覆盖的对象范围。可在互不依赖时并行收集数据与素材，文案确定后再实施对应视觉修改。

每个子任务交回：任务状态、输入母版哈希、页面工作标识、修改对象清单、产物路径、来源、检查项目和未解决项。主执行者核对母版是否变化；已过期的补丁重新匹配，不直接覆盖最新稿。

合并后统一检查字体、页序、内容回退、照片来源和双版本一致性。不要让子任务分别发布“最终版”。只有通过本轮门槛的主稿可以进入最终导出。

## 不可异步承诺

工具能真实创建和追踪任务，才能报告运行状态。没有异步执行能力，不说“后台继续”“稍后给你”；本轮交付能完成的内容并说明阻断。
