# 完整操作流程

## 阶段0：明确范围，而不是重新问已知问题

把当前请求分成四类：内容、字体/样式、素材、页面顺序。先确定是否允许修改文件；用户仅要总结或Skill时，流程到说明与打包即止。

开始时用一两句话说明本轮具体处理范围。不要用长计划替代工作，也不要在多轮连续批注后遗失前面已经明确的要求。记录本轮新要求时保留其他未冲突要求。

## 阶段1：恢复原稿与资产

优先顺序：用户指定母版 → 已确认的原生可编辑稿 → 对应源归档 → 旧版本用于对照。最新图片版用于页序与视觉核对，但不自动覆盖原生稿。

当前附件有已确认挂载路径时直接用；资料库文件按可见文件引用读取、需要编辑时再复制；连接器原生资源走相应连接器。不要不断检索同一个已经找到的文件。

复制前记录源路径/来源、版本、大小、页数和SHA-256。备份、工作副本与输出分开放置。原始文件保留不动，原稿与中间稿不得因文件名相同而被覆盖。

只有图片版时，先查可编辑源稿。确实无法取得时，说明原生对象无法直接修改；可以完成文案/映射/素材准备。未经说明不得将截图覆盖版标成全可编辑版。

## 阶段2：页序映射

每页建立`slide_uid`作为本项目工作标识，如`S001`；页码是随版本变化的属性。记录源稿页面部件、当前页码、视觉标题、主要照片、所属章节和目标顺序。

对照用户最新图片版，用标题+图片特征+内容组合确认。相同标题不够；重复页面、合并页面与替换素材要人工判断。基于文本/图片哈希的自动匹配只提供候选，图片版与可编辑版照片哈希通常不同。

有“刚刚是20面，我发错了”等纠正时，更新该条任务指向，不把先前错指页也一起修改。合并两页先归纳两页必须保留的证据，再排版，不以删除一页代替合并。

## 阶段3：变更合同与防回退

每条要求要有唯一编号、原话、作用范围、修改对象、必须保留项、被替代条目和验证方式。

典型对象：左侧大标题、右上能力标签、C1—C5名称、指定三行正文、企业招聘截图、封面人物、封面/尾页Logo、原始数据图表、证书原件。

将内容、字体和版式分别保存。改标题时保留字体；恢复字体时保留最新标题；换Logo时保留两者。允许合理扩大文本框和间距以防溢出，但不顺带替换整页视觉风格。

对被用户否决的版本建立`rejected_variants`，只作历史比对，不重新合并。默认只在明确变更范围内改动。

## 阶段4：证据与素材准备

每页先回答：这一页想证明什么？已有证据是什么？结论是否超出证据？素材与说明是否一致？

证据分为用户原件、官方来源、可靠公开来源、推导/估算、设计示意、未验证。分类要跟随到素材/数据记录，不因排版简化丢失。

照片使用真实原件。对低清素材，先找高分辨率版本或其他真实镜头；找不到就降低展示面积或提示限制。不能声称锐化、上采样或4K导出已经恢复真实细节。

截图保留必要的机构标识、标题或职位名称。来源和抓取日期记在资产记录及PPT备注；需要读者理解的统计口径仍在页面可见处。

## 阶段5：文案与视觉实施

先确认本页一句话主标题，再安排证据、动作、结果。标题不应仅是抽象能力堆叠；用“以什么实践/材料，体现什么能力/结论”的自然句式表达。

常见布局动作：
- 文多图区少：缩短重复解释，增加真实证据图，而非添加无关装饰照。
- 下半页拥挤：将图注与应用短语分层，减少同义重复，预留页脚和结论空间。
- 文字孤立：用浅色卡片、分组标题、边框和有限强调构成信息组。
- 对比页面：统一同级字体、字重、颜色和模块宽度。
- 奖项/媒体页：突出证书、项目或媒体原件，不让新的分析图表抢走用户指定重点。
- 招聘/访谈页：左侧真实招聘网页，右侧访谈者与现场图片，人物、单位、职位、启示对应。

不要对整个文件做无语义的全局替换。“拟”在“模拟”“拟合”中是正常词；“本人”删除后检查语法；删旧职业词时保留历史真实岗位经历。

使用原生PPT对象修改。不要把图片中的文字误当原生正文；不要叠加多层重复文字或用白色块粗糙遮盖米色背景。需要清理背景时优先回到原始底图/矢量对象，无法无损处理要说明。

## 阶段6：合并与回归

主执行者合并三条工作线结果，检查：页序、标题、字体、颜色、引用素材、证据内容以及本轮之外的改动。

比对修改前后：允许变化是否准确发生？不允许变化是否保留？一个页面的排版修复有没有造成邻近文字、页脚、能力标签、图注或Logo遮挡？

已确认的模板、字体、艺术字、人物原图和数字需要作为回归检查项，不仅检查新增内容。对全套同类问题做搜索和渲染核对，但未经授权不扩大到无关内容重写。

## 阶段7：导出与验收

先冻结可编辑主稿的版本和哈希，再导出图片版。两版采用同一页序、内容、备注与来源信息。

保留原比例。只在16:9时采用3840×2160；用户输入比例不同不能机械套用。图片版用足够分辨率的单页图，确保普通播放尺寸清晰，必要时调整压缩参数以满足50MB以内。

顺序：结构预检 → 修改页放大检查 → 全套逐页检查 → 两版逐页对照 → 文件打开与大小检查 → 下载文件路径核实。没有视觉渲染就不能把结构预检称作逐页检查通过。

## 阶段8：交付与迁移

提供明确版本的可编辑版、图片版与关键预览；源包仅包含必要源文件、素材、来源、修改清单及恢复说明。不要把所有旧版本无限叠加到每次源包中，造成体积失控。

图片版、可编辑版各自说明字节数和对象可编辑边界。不提供伪造Library地址或凭标题推测的sandbox链接。下载失败时重新验证路径与当前文件，必要时复制到当前对话的可下载输出目录，保留原件并使用清楚的新文件名。

接续说明至少包含当前母版、页序、最新锁定要求、拒用内容、三条工作线真实状态、未完成项和产物位置。不要在说明中保存过期签名URL、密钥或不必要个人材料。
