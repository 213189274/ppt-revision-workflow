# 项目适配

## 职业规划展示

根据用户已确认的目标岗位、职业分类和行业方向，核对背景、政策、招聘证据、调研、职责和能力。能力框架只用于明确指定的章节。

## 食品创新赛适配建议

进入新项目时先读取对应PPT、策划书、真实产品/实验/团队材料和赛事要求。不把职规赛的页数、姓名、职业目标、招聘页或能力模型迁移进来。

可按现有材料核对以下链条，而不是强行新增每个章节：

`需求与痛点 → 产品与原料 → 工艺或技术 → 实验/评价依据 → 产品展示与应用 → 团队成果与实施计划`

每页用真实证据支撑它要说明的内容：真实产品照、原料与设备、工艺现场、实验记录、检测材料、感官或用户评价原始记录、实践与合作材料。缺少的材料标为待提供，不生图补齐。

可编辑流程图、分析图表和结构示意允许作为**图形对象**绘制，但不能伪装成真实实验照片或实测结果；用户要求仅真实图片时，任何示意图用途须清晰且不改变该限制。

涉及营养、品质、保质期、安全、口感或经济效果的结论，必须能对应材料，不把“设计目标”写成“已验证结果”。涉及标准或规范的外部信息，使用可靠原文并核验适用范围。

### 三条工作线在食品创新赛中的使用

- 数据线：行业需求、原料与市场数据、政策/标准出处及真实行业素材。
- 审校线：产品名称、技术逻辑、证据、成果归属、已完成与计划的区分。
- 视觉线：真实产品/实验图的排版、工艺说明、关键结果和原生对象编辑。

## C. 其他已有PPT

保留共同流程：原稿接续、页序映射、最新要求、真实证据、字体合同、主稿唯一、逐页检查、双版本同步。项目内容框架由其原稿和用户材料决定，不从其他项目的示例中自行补齐。
